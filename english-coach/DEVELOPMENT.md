# Android development builds

`debug-signing-key.base64` is a PUBLIC development-only Android key with the standard debug password `android`. It exists solely to keep APK development updates compatible across GitHub runners. Never use it for production/store releases or sensitive distribution.

The older v2.0 APK used a temporary runner key. It may require uninstalling before installing v2.1, which removes local study history. Builds from v2.1 onward use this stable development key.

Pronunciations are bundled offline from CMUdict (US English). CMUdict license is included as CMUDICT-LICENSE.txt. Portuguese hints are approximate learning aids; IPA and device audio provide additional pronunciation references.
